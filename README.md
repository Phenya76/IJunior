# Binance Price Alert Bot - Инструкция по установке и использованию

## 📋 Описание

Десктопное приложение для отслеживания ценовых уровней на бирже Binance с отправкой системных уведомлений Windows. Приложение работает без Telegram и других заблокированных сервисов.

## ✨ Возможности

- **Мониторинг в реальном времени** - проверка цен каждые 5 секунд
- **Поддержка всех токенов Binance** - более 2000 торговых пар с USDT, BUSD, BTC, ETH, BNB
- **Гибкие условия** - установка уровней на повышение (above) или понижение (below)
- **Системные уведомления Windows** - всплывающие уведомления при достижении цены
- **Сохранение уровней** - все уровни сохраняются в файл и не теряются после закрытия
- **Поиск токенов** - удобный поиск по названию токена
- **Управление уровнями** - активация, деактивация, удаление
- **Лог событий** - история всех действий и сработавших уведомлений

## 🚀 Установка на Windows

### Вариант 1: Запуск из исходного кода (рекомендуется для разработки)

1. **Установите Python** (если не установлен):
   - Скачайте с https://www.python.org/downloads/
   - При установке отметьте галочку "Add Python to PATH"

2. **Установите зависимости**:
   ```bash
   pip install requests plyer
   ```

3. **Запустите приложение**:
   ```bash
   python binance_alert_bot.py
   ```

### Вариант 2: Создание EXE-файла (для распространения)

1. **Установите PyInstaller**:
   ```bash
   pip install pyinstaller
   ```

2. **Создайте EXE-файл**:
   ```bash
   pyinstaller --onefile --windowed --name "BinanceAlert" binance_alert_bot.py
   ```

3. **Найдите готовый файл**:
   - EXE-файл будет в папке `dist/BinanceAlert.exe`
   - Скопируйте его в удобное место и запускайте двойным кликом

## 📖 Как пользоваться

### Добавление уровня

1. В поле **"Символ"** начните вводить название токена (например: `BTC`, `ETH`, `SOL`)
2. Выберите нужный символ из выпадающего списка (например: `BTCUSDT`)
3. В поле **"Цена"** введите желаемый уровень цены
4. Выберите **условие**:
   - `above` - уведомление когда цена станет **выше** указанного уровня
   - `below` - уведомление когда цена станет **ниже** указанного уровня
5. Нажмите кнопку **"➕ Добавить"**

### Управление уровнями

- **Удалить** - выберите уровень в списке и нажмите "🗑️ Удалить"
- **Деактивировать** - временно отключить проверку уровня (можно реактивировать)
- **Активировать** - включить ранее деактивированный уровень
- **Очистить сработавшие** - удалить все уровни, которые уже сработали

### Примеры использования

#### Пример 1: Уведомление когда Bitcoin достигнет $70,000
```
Символ: BTCUSDT
Цена: 70000
Условие: above
```

#### Пример 2: Уведомление если Ethereum упадет до $2,000
```
Символ: ETHUSDT
Цена: 2000
Условие: below
```

#### Пример 3: Несколько уровней для одного токена
Добавьте несколько уровней для BTCUSDT:
- $68,000 (below) - если упадет
- $72,000 (above) - если вырастет
- $75,000 (above) - цель по прибыли

## ⚙️ Настройки

В коде приложения можно изменить следующие параметры:

- **Интервал проверки** (строка ~230): `self.check_interval = 5` - проверка каждые 5 секунд
- **Таймаут уведомления** (строка ~195): `timeout=10` - уведомление исчезнет через 10 секунд
- **Котируемые активы** (строка ~32): можно добавить другие пары кроме USDT, BUSD, BTC, ETH, BNB

## 🔔 Как работают уведомления

Приложение использует библиотеку `plyer` для отправки системных уведомлений Windows:

1. Когда цена достигает установленного уровня
2. Появляется всплывающее уведомление в правом нижнем углу экрана
3. Уведомление содержит:
   - Название токена
   - Текущую цену
   - Направление движения (выше/ниже)
   - Время срабатывания

## ⚠️ Важные замечания

1. **Приложение должно работать постоянно** - закройте окно = остановка мониторинга
2. **Нужен интернет** - для получения актуальных цен с Binance
3. **Не является торговым ботом** - только уведомления, никаких сделок не совершает
4. **API Binance публичное** - не требует ключей API, нет ограничений по частоте запросов

## 🛠️ Решение проблем

### Уведомления не приходят
- Проверьте настройки уведомлений Windows
- Убедитесь, что приложение не свернуто в трей
- Проверьте консоль на наличие ошибок

### Ошибка подключения к Binance
- Проверьте интернет-соединение
- Возможно временные проблемы с API Binance
- Попробуйте перезапустить приложение

### Приложение не запускается
- Убедитесь, что установлен Python 3.8+
- Проверьте установку зависимостей: `pip install requests plyer`
- Запустите из консоли для просмотра ошибок
